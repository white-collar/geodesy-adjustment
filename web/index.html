Опорные точки

CSV: id,x,y

Пункты с точно известными координатами. Координаты всех остальных точек, упомянутых в измерениях, вычисляются автоматически — вводить их не нужно.

ТипFromToTo2Значениеσ

Схема связей измерений

Обновляется по мере ввода. Схематично (не в масштабе) — показывает, какие пункты связаны какими измерениями; помогает сразу заметить изолированный пункт. Клик по строке измерения слева подсвечивает её на схеме; клик по схеме снимает подсветку.
